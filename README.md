### 🌊 FloodGuard AI
**River Flood Risk Intelligence**

`Python` `Random Forest` `Scikit-learn` `Plotly` `Streamlit`

A machine learning research prototype that analyzes historical Indian river monitoring data to estimate next-day water-level risk.

**Highlights**
- Analyzed **3.86M+ labeled observations** across 932 river monitoring stations.
- Achieved **97.91% accuracy** and **0.85 High-Risk F1-score**; the persistence baseline achieved 98.59% accuracy.
- Developed a separate escalation model with **34.3% recall** and an interactive Streamlit monitoring dashboard.

[![View Project](https://img.shields.io/badge/Explore_FloodGuard-0F766E?style=for-the-badge&logo=github&logoColor=white)](https://github.com/namrataamali/FloodGuard)

<sub>Historical research prototype; not an operational flood warning system.</sub>

### ⚡ EnergyWatch AI
**Electricity Consumption Analytics & Anomaly Detection**

`Python` `Isolation Forest` `Pandas` `Plotly` `Streamlit`

An energy analytics application that explores household electricity consumption and identifies statistically unusual usage patterns.

**Highlights**
- Analyzed **34,168 hourly electricity records** using Isolation Forest.
- Identified **1,709 anomalies** with a **0.5853 Silhouette Score** for predicted-group separation.
- Built an interactive dashboard with consumption trends, anomaly insights, and downloadable reports.

[![View Project](https://img.shields.io/badge/Explore_EnergyWatch-0F766E?style=for-the-badge&logo=github&logoColor=white)](https://github.com/namrataamali?tab=repositories)

<sub>Detected anomalies do not necessarily indicate electrical faults.</sub>

### ⚙️ MachineGuard AI
**Predictive Maintenance & Equipment Failure Intelligence**

`Python` `Random Forest` `Scikit-learn` `Pandas` `Streamlit`

A predictive maintenance application that estimates machine failure risk and provides rule-based maintenance recommendations.

**Highlights**
- Trained and evaluated a Random Forest model using **10,000 equipment records**.
- Improved failure detection recall from **40% to 74%** through threshold optimization.
- Achieved approximately **70% F1-score** and developed an interactive risk assessment dashboard.

[![View Project](https://img.shields.io/badge/Explore_MachineGuard-0F766E?style=for-the-badge&logo=github&logoColor=white)](https://github.com/namrataamali?tab=repositories)

<sub>Educational application using the synthetic AI4I 2020 dataset.</sub>

### 🩺 DiaSense AI
**Diabetes Prediction & Interactive Health Analytics**

`Python` `Logistic Regression` `Scikit-learn` `Seaborn` `Streamlit`

An end-to-end machine learning application combining diabetes prediction with interactive health data exploration.
