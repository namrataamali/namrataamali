### 🌊 01 — FloodGuard AI

**River Flood Risk Intelligence & Predictive Analytics**

`Python` `Random Forest` `Scikit-learn` `Pandas` `Plotly` `Streamlit`

A machine learning research prototype that analyzes historical Indian river monitoring data to estimate next-day water-level risk.

**Key Highlights**
- Analyzed **3.86M+ labeled observations** across 932 river monitoring stations.
- Achieved **97.91% accuracy** and **0.85 High-Risk F1-score**; a persistence baseline achieved 98.59% accuracy.
- Developed an escalation model with **34.3% recall** and an interactive Streamlit monitoring dashboard.

[![Explore Project](https://img.shields.io/badge/Explore_FloodGuard_AI-B87552?style=for-the-badge&logo=github&logoColor=white)](https://github.com/namrataamali/FloodGuard)

<sub>Historical research prototype; not an operational flood warning system.</sub>

### ⚡ 02 — EnergyWatch AI

**Electricity Consumption Analytics & Anomaly Detection**

`Python` `Isolation Forest` `Scikit-learn` `Pandas` `Plotly` `Streamlit`

An energy analytics application that explores household electricity consumption patterns and identifies statistically unusual usage.

**Key Highlights**
- Analyzed **34,168 hourly electricity records** using Isolation Forest.
- Identified **1,709 anomalies**, with a **0.5853 Silhouette Score** for predicted-group separation.
- Built an interactive dashboard with consumption trends, anomaly visualizations, and downloadable reports.

[![Explore Project](https://img.shields.io/badge/Explore_EnergyWatch_AI-B87552?style=for-the-badge&logo=github&logoColor=white)](https://github.com/namrataamali?tab=repositories)

<sub>Statistical anomalies do not necessarily represent electrical faults.</sub>

### ⚙️ 03 — MachineGuard AI

**Predictive Maintenance & Equipment Failure Intelligence**

`Python` `Random Forest` `Scikit-learn` `Pandas` `Streamlit`

A machine learning application designed to estimate equipment failure risk and support preventive maintenance decisions.

**Key Highlights**
- Developed a Random Forest model using **10,000 equipment records**.
- Improved failure detection recall from **40% to 74%** through threshold optimization.
- Achieved approximately **70% F1-score** and built an interactive risk assessment dashboard.

[![Explore Project](https://img.shields.io/badge/Explore_MachineGuard_AI-B87552?style=for-the-badge&logo=github&logoColor=white)](https://github.com/namrataamali?tab=repositories)

<sub>Educational application using the synthetic AI4I 2020 dataset.</sub>

### 🩺 04 — DiaSense AI

**Diabetes Prediction & Interactive Health Analytics**

`Python` `Logistic Regression` `Scikit-learn` `Pandas` `Seaborn` `Streamlit`

An end-to-end machine learning application combining diabetes prediction, model evaluation, and interactive health data exploration.
